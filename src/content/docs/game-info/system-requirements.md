These are the official PC system requirements currently published on the Steam store page for **Agefield High: Rock the School**. Specs can still change after patches, so confirm against the live Steam listing if you are buying or upgrading hardware.

Source: official Steam store page.

## Minimum Requirements

| | |
| --- | --- |
| OS | Windows 10 / 11 (64-bit processor and operating system required) |
| Processor | AMD Ryzen 5 2600X / Intel Core i7-7700K |
| Memory | 16 GB RAM |
| Graphics | NVIDIA GTX 1070 (8GB) / AMD Radeon RX 580 (8GB) |
| DirectX | Version 12 |
| Storage | 15 GB available space |
| Additional Notes | SSD Required |

## Recommended Requirements

| | |
| --- | --- |
| OS | Windows 10 / 11 (64-bit processor and operating system required) |
| Processor | AMD Ryzen 5 7600X / Intel Core i7-12700K |
| Memory | 32 GB RAM |
| Graphics | NVIDIA RTX 3080 / AMD Radeon RX 6950 XT |
| DirectX | Version 12 |
| Storage | 15 GB available space |
| Additional Notes | SSD Required |

:::note
Figures above match the live Steam listing as of August 13, 2026. Older third-party pages that list different GPU or storage numbers should not be trusted over Steam.
:::

## Controller Support & Keybinds

### Does Agefield High Support Controllers?

The Steam store currently lists **Full Controller Support** and **Xbox controller support**.

### Does Agefield High Support Xbox and PlayStation Controllers?

Xbox controller support is listed on the Steam storefront. PlayStation / DualSense actual behavior, on-screen button prompts, and vibration are <span class="unconfirmed">not verified</span>.

### Can You Remap Keyboard Controls?

The full range of keyboard remapping has not yet been verified. This page does not publish a default keybind table or claim that every key can be rebound.

## Quick answers

- **SSD:** Yes — Steam lists “SSD Required” for both tiers.
- **Storage:** 15 GB available space.
- **Windows 10:** Yes — Windows 10 / 11 is listed.
- **DirectX:** Version 12.

### Does Agefield High require an SSD?

Yes. The official Steam system requirements list **SSD Required** for both minimum and recommended configurations.

### How much storage does Agefield High need?

Steam currently lists **15 GB available space**.

### Does Agefield High run on Windows 10?

Yes. Official requirements list **Windows 10 / 11** with a 64-bit processor and operating system.

### Are recommended specs available yet?

Yes. Steam currently publishes both minimum and recommended system requirements.
