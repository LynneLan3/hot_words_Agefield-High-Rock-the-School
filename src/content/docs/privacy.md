# Privacy

This site uses Google Analytics 4 to understand aggregate usage, such as page views, outbound link clicks, approximate location, device type, and referral source. The site uses this information to improve guide coverage and measure which sources, evidence links, and content links are useful.

Google Analytics may set cookies or use similar browser storage when it loads on the production site. Analytics is configured to load only on the production hostname, not on localhost or preview deployments.

The site does not sell visitor data. Hosting providers may still process routine technical logs, such as IP address and user agent, to deliver and secure the site.
