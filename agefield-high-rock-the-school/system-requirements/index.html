Agefield High: Rock the School System Requirements

Last Updated: August 9, 2026 · Source: official Steam store page

These are the official PC system requirements currently published on the Steam store page for Agefield High: Rock the School. Specs can change before or after launch, so treat this as a pre-release reference.

Minimum Requirements

OS Windows 10 / 11 (64-bit processor and operating system required)
Processor AMD Ryzen 5 2600X / Intel Core i7-7700K
Memory 16 GB RAM
Graphics NVIDIA GTX 1070 (8GB) / AMD Radeon RX 580 (8GB)
DirectX Version 12
Storage 15 GB available space
Additional Notes SSD Required

Recommended Requirements

OS Windows 10 / 11 (64-bit processor and operating system required)
Processor AMD Ryzen 5 7600X / Intel Core i7-12700K
Memory 32 GB RAM
Graphics NVIDIA RTX 3080 / AMD Radeon RX 6950 XT
DirectX Version 12
Storage 15 GB available space
Additional Notes SSD Required
Figures above match the live Steam listing as of August 9, 2026. Older third-party pages that list different GPU or storage numbers should not be trusted over Steam.

Quick answers

  • SSD: Yes — Steam lists “SSD Required” for both tiers.
  • Storage: 15 GB available space.
  • Windows 10: Yes — Windows 10 / 11 is listed.
  • DirectX: Version 12.

Yes. The official Steam system requirements list SSD Required for both minimum and recommended configurations.

Steam currently lists 15 GB available space.
